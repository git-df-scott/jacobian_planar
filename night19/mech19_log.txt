M1  the weight grading  w(x) = -1, w(y) = +1
==============================================================================
  w-weights of the monomials of P: {'(1, 2)': 1, '(0, 1)': 1}   -> P is w-isobaric of weight {1}
  for every monomial of every carrier i+j <= 10, every monomial of [P, x^i y^j] has w-weight (j - i) + 1: True
  so [P,Q] = 1 (w-weight 0) can only be fed by the w-weight (-1) part of Q,
  which is spanned by { x^{m+1} y^m : m >= 0 }, and the target row set is
  the w-weight 0 line { (x y)^n : n >= 0 }.  Both are ONE-PARAMETER chains.
