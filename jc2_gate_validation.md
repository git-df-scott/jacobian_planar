- G1 is the load-bearing gate: two implementations that share no arithmetic code (sympy diff/expand vs hand-rolled Fraction-pair dict convolution) must agree exactly. - G2 is deliberately conservative (may reject a non-minimal true counterexample); the reduction argument is in the module docstring.

- G3 marks its mode (GENERIC resultants over Q(p,q) / SPECIFIC rational-target exact fiber counts / NONE-infeasible). Specific-target counts are evidence, exact but per-target; for an etale Keller candidate they equal the generic count.

- G6 is a necessary-condition re-check mod 3 primes = 1 (mod 3) (so sqrt(-3) reduces), never sufficient on its own.

- No ACCEPT path is exercised here: no known Keller counterexample exists to test it. The gate's default is REJECT, so an all-gates bug that errors out yields REJECT, not a false ACCEPT.
