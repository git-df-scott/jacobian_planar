# Vitushkin-covering search, 2026-09-03 (interim)

Target-side formulation. A plane Keller counterexample of geometric degree D is
equivalent to: a curve S in the target plane whose components are polynomial
curves (Jelonek), and a transitive representation rho of pi_1(C^2 - S) in S_D,
generated by meridian images, such that

1. every meridian mu_i has n_i >= 1 fixed points (the image of F meets every
   component of S) and e_i = D - n_i >= 1 moved points;
2. over a singular point p of S the staying sheets are the common fixed points
   of the local link group image, s_p = |Fix rho(L_p)|;
3. Euler: 1 = D(1 - m + nu) + sum_i n_i (1 - k_i) + sum_p s_p, with m the
   number of components, nu = sum_p (r_p - 1) the branch excess, k_i the number
   of branches of S_i over singular points;
4. fibres: D - sum_i alpha_i e_i <= -1 and D - sum_i beta_i e_i <= -1 where
   (alpha_i, beta_i) is the bidegree of the parametrisation of S_i;
5. the source X is simply connected: H = Stab(1) equals the normal closure of the
   meridian lifts on staying sheets;
6. (not yet implemented) X affine and simply connected at infinity, then
   Ramanujam gives X = C^2, and Riemann existence plus Grauert-Remmert make the
   cover algebraic, so a configuration passing 1-6 IS a counterexample.

Tools: `bm.py` (braid monodromy by root tracking, Zariski-van Kampen
presentation, transported local meridians, exact singular-point identification
from the parametrisation), `gapcheck.g` (low-index enumeration and tests 1-5),
`runcurve.py`, `sweep*.py` (curve libraries), logs `sweep*.log`.

Validation: cuspidal cubic gives B_3; nodal cubic gives Z; transport convention
fixed by requiring the local braid relation at every cusp in every
representation (convention A failed in 13 representations, B in none).

## Results so far

- Every curve with only ordinary cusps and nodes, and every reducible
  configuration tried (cuspidal cubic with lines, parabolas, second cubics),
  fails test 3 at every D <= 8: nodes force common fixed points and the Euler
  count comes out 0 or 2, never 1.
- First passes of tests 1-4: every (3,5) and (3,6) curve carrying a (2,5)-cusp,
  an ordinary cusp and a node (family b' = (t^2-1) h(t) with h'(1) = 0 for
  a = t^3 - 3t). The representation is unique: D = 6, image A5 acting on six
  points (PSL(2,5) on P^1(F_5)), meridians double transpositions with n = 2,
  e = 4, staying sheet counts (1, 0, 0) at the (2,5)-cusp, node, ordinary cusp.
  Fibres of P have chi = -6, fibres of Q have chi = -14 or -18.
- That configuration fails test 5: H1(X) = Z^2. Analysis (`/tmp/h1.g`): H1 of
  the unramified cover Y is Z^3, killing the three staying meridians leaves Z^2,
  and killing the loops around the escaping points as well leaves Z/2. So the
  surviving cycles are loops around escaping branches, i.e. loops at infinity of
  X; X is not contractible.
- No representation passing tests 1-4 has been found on any curve without a
  (2,5)-cusp.
