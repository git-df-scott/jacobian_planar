## 07:45Z The y-adic systems are linear chains

Measured on the (9,27) c' = 0 eps-swap chart (18 variables after gauge): after the first block (26 generators, nonlinear, in c_3, c_4, c_5), every later block is linear in its three new variables (rows j of the driver polygon enter Q_{j+1} only through P_j Q_1', which is linear). So the shape system is: a base variety from block 0 (here the line c_4 = c_5 = 0, c_3 free, read off a four-element Groebner basis) followed by a chain of small linear solves over the function field of the free parameters. Rank deficiencies add free parameters; compatibility rows add constraints. `lincascade2.py` implements this exactly over F_p (python-flint, fraction-free elimination), branching on pivots (a monomial pivot gives a zero-branch on its variables, a non-monomial pivot gives a constraint branch) and on monomial constraints, with branch deduplication.

Result on the 18-variable chart at p = 65521 (branch limit 2000, hit once, so the enumeration is incomplete on the c_3 = 0 side):

|---|---|---|---|
| generic (c_3 nonzero, pivots powers of c_3) | c_4, c_5, c_8 | 9: c_3, c_6, c_7, c_9, c_11, c_13, c_14, c_16, c_17 | 74 polynomials, up to thousands of terms |
| c_3 = 0 side | c_3, c_4, c_5, c_7, c_8, c_11 | 4 to 7 | about 10 each, 215 pivot-constraint variants |

The first constraints of the generic branch are binary quadratic forms in (c_3 c_6, c_7), i.e. the shape variety, if nonempty, is carved out of a 9-parameter space by dense high-degree relations. The compatibility system of the generic branch (74 polynomials in 9 variables plus c_3 t - 1) is being run in msolve (7 GB, 2400 s) and Singular (3.5 GB, 2400 s). The branching cascade with plain Groebner steps (`cascade_branch.py`) reached the same kind of wall on both charts: on the case (2) chart it found 3 EMPTY branches and 2 WALL branches (runs of up to 1009-element bases in 14 variables).
