# night15 — THE PERIOD SCREEN

A necessary condition for the existence of a Keller mate, derived, implemented,
controlled, and run at scale. Measurements only.

---

## 1. Derivation

Let `P, Q` in `Q[x,y]` with

    P_x Q_y - P_y Q_x = 1.                                              (K)

Then

    dP ^ dQ = (P_x dx + P_y dy) ^ (Q_x dx + Q_y dy)
            = (P_x Q_y - P_y Q_x) dx ^ dy
            = dx ^ dy.                                                  (1)

Fix `c` and let `F_c = {P = c}` (the affine fibre in `C^2`). Define the
**Gelfand–Leray form** on `F_c`

    eta = dy / P_x = - dx / P_y.                                        (2)

*Check that the two expressions agree and that `eta` is the Gelfand–Leray form.*
On `F_c` we have `dP = 0`, i.e. `P_x dx + P_y dy = 0`, so `P_y dy = -P_x dx`;
dividing by `P_x P_y` gives `dy/P_x = -dx/P_y`. And

    dP ^ (dy / P_x) = (P_x dx + P_y dy) ^ dy / P_x = P_x dx ^ dy / P_x = dx ^ dy,

which is (1). So `eta` is exactly the form whose wedge with `dP` is the volume
form.

*Restriction of `dQ`.* Where `P_x != 0`, use `y` as a local coordinate on `F_c`;
then `dx = -(P_y/P_x) dy` and

    dQ|_{F_c} = (Q_x dx + Q_y dy)|_{F_c}
              = (Q_y - Q_x P_y / P_x) dy
              = (P_x Q_y - P_y Q_x) dy / P_x
              = dy / P_x  =  eta,                        by (K).        (3)

Symmetrically where `P_y != 0`. So under (K),

    **eta = dQ|_{F_c}  is EXACT on every fibre F_c.**

Since `Q|_{F_c}` is a single-valued function on `F_c`, the integral of `dQ` over
any closed cycle of `F_c` is zero. Hence

> **(NECESSARY CONDITION — the period screen.)** If `P` has a Keller mate, then
> for every `c` and every closed cycle `gamma` in `H_1(F_c)`,
>
>     integral over gamma of eta  =  0.

**No degenerate cases.** All the `P` screened here are gradient-unimodular:
there is an exact Bezout identity `A P_x + B P_y = 1` in `Q[x,y]`, so `P_x` and
`P_y` have no common zero anywhere over `C`. Every fibre `F_c` is therefore
smooth, and by (2) `eta` is a holomorphic 1-form on all of `F_c` (at any point
at least one of `P_x`, `P_y` is nonzero, and the two expressions agree).

**Two standard consequences used below.**

* *(Residues.)* Let `Fbar_c` be the smooth compactification of `F_c` and
  `p_1..p_n` the punctures. `eta` is holomorphic on `F_c`, so its only poles on
  `Fbar_c` are at punctures. The period of `eta` over a small loop around `p_i`
  is `2 pi i Res_{p_i}(eta)`, and those loops lie in `F_c`. So **a nonzero
  residue at any puncture is a nonzero period.**
* *(Residue theorem — control C3.)* On the compact `Fbar_c` the residues of a
  meromorphic 1-form sum to zero; the affine points contribute zero, so
  **the residues over all punctures must sum to zero.** This is asserted on
  every fibre measured.
* *(Positive genus.)* If `eta` is holomorphic on the compact `Fbar_c` and
  `genus(Fbar_c) >= 1`, then `eta != 0` forces a nonzero period: if all periods
  vanished, `eta = df` with `f` holomorphic on a compact Riemann surface, so `f`
  is constant and `eta = 0`. Moreover `H_1(F_c) -> H_1(Fbar_c)` is surjective
  (deleting points only adds cycles), so a nonzero period on `Fbar_c` is a
  nonzero period on `F_c`.

**A reformulation used to sanity-check the direction of the condition.** On the
smooth affine `F_c` the module of 1-forms is free of rank 1 generated by the
nowhere-vanishing `eta`, and for `F` in the coordinate ring `dF = [P,F] * eta`
where `[P,F] = P_x F_y - P_y F_x`. So all periods vanish iff `1` is in the image
of the Jacobian derivation on `Q[x,y]/(P-c)`, i.e. iff `[P,Q] = 1` is solvable
**modulo `(P - c)`**. The period screen is exactly the per-fibre relaxation of
the mate system — which is why it can only obstruct, never produce, a mate.

## 2. Implementation — two instruments

### 2.1 EXACT-HE — closed form, exact over `Q`, for `deg_y P = 2`

Write `P = g(x) y^2 + h(x) y + k(x)` with `g != 0`. Put `w = 2 g y + h`. Then on
`{P = c}`

    w^2 = h^2 - 4 g k + 4 g c  =:  Delta_c(x),

and `Q(x,y) = Q(x,w)`, so the fibre's function field is the hyperelliptic field
`w^2 = Delta_c`. Crucially `P_y = 2 g y + h = w`, so by (2)

    **eta = - dx / w,     w^2 = Delta_c(x).**

Factor `Delta_c = s(x)^2 * Delta_0(x)` with `Delta_0` squarefree; the smooth
model is `w_0^2 = Delta_0`, `w = s w_0`, and

    eta = - dx / ( s(x) w_0 ),      genus = floor((deg Delta_0 - 1)/2)  (0 if <= 2).

The verdict is then read off with no series expansion at all:

| case | hypotheses | verdict | witness |
|---|---|---|---|
| A | `deg Delta_0 >= 3`, `s` constant | NONVANISHING | `dx/w_0` is a nonzero **holomorphic** form on a compact curve of genus >= 1 |
| B | `deg Delta_0 = 2`, `s` constant | NONVANISHING | residues `-+ 1/(s sqrt(alpha))` at the two places over `x = infinity`, `alpha = lc(Delta_0)` |
| C | `deg Delta_0 = 1`, `s` constant | VANISHING | `x = (w_0^2 - beta)/alpha` gives `eta = -2 dw_0/(s alpha)`: globally exact, genus 0, one puncture, `H_1 = 0` |
| D | `deg Delta_0 = 0`, `s` constant | VANISHING | `eta` is a constant multiple of `dx` |
| E | `s` nonconstant with a simple root `a`, `Delta_0(a) != 0` | NONVANISHING | simple pole; `Res = -1/(s'(a) (+- sqrt(Delta_0(a))))` |
| F | otherwise | deferred to NUM-MONO | — |

Case B derivation: near either place over `x = infinity`, with `u = 1/x`,
`w_0 = +- sqrt(alpha)/u (1 + O(u))` and `dx = -du/u^2`, so
`eta = -+ du/(s sqrt(alpha) u) (1 + O(u))`, residue `-+ 1/(s sqrt(alpha))`.
Case E: for a simple root, `1/s(x) = 1/(s'(a)(x-a)) + O(1)` and `w_0` is a unit,
giving the stated residue on each of the two places.

C3 holds identically in this instrument: in B and E the two residues are exact
negatives, so the sum over all places is symbolically `0`.

Implementation: `exact_he15.py` (sympy polynomial algebra over `Q`; the only
irrationality that ever appears is a single square root).

### 2.2 EXACT-G1 — closed form, exact, for the whole v-power family

`exact_g1_15.py`. For `P = h0 v + c (x-a)^n v^m` with `v = y + t(x)/2` and
`m >= 2`, the shears `y -> y - t(x)/2` and `x -> x + a` have Jacobian 1, so by
(G3) they leave every period unchanged and one may take

    P = h0 y + c x^n y^m.

On `{P = lam}`, `c x^n y^m = lam - h0 y` and `P_x = c n x^(n-1) y^m`, so

    eta = dy/P_x = x dy / ( n (lam - h0 y) ).

Setting `z = c y^m x` turns the fibre into the **superelliptic curve**

    z^n = c^(n-1) y^(m(n-1)) (lam - h0 y) =: R(y),
    eta = z dy / ( c n y^m (lam - h0 y) ).

Places (for `lam != 0`), with `d0 = gcd(n,m)` and `dinf = gcd(n,m-1)`:
`y = 0` (there `x -> infinity`) carries `d0` **punctures**; `y = lam/h0` (there
`x = 0`) is one honest **affine** point with ramification `n`; `y = infinity`
(there `x -> 0`) carries `dinf` **punctures**. Riemann–Hurwitz gives

    2g = n + 1 - gcd(n, m) - gcd(n, m-1),

which for `m = 2` is `n - gcd(n,2)`, i.e. `floor((n-1)/2)`, agreeing with
EXACT-HE. Expanding `eta` in a local parameter at each place:

* at `y = infinity`, `eta/d tau = const * tau^((m-1)/dinf - 1) d tau` — for
  `m >= 2` the exponent is `>= 0`, so `eta` is holomorphic there and has no
  residue;
* at `y = 0`, with `y = tau^(n/d0)`,

      eta/d tau = tau^((n-m)/d0 - 1) * (1/(c d0)) c^((n-1)/n) N(tau^(n/d0))^((1-n)/n)

  with `N = lam - h0 y`, and the residue is the coefficient of `tau^k`,
  `k = (m-n)/d0`, in the binomial series of `N^((1-n)/n)` — nonzero exactly when
  `k >= 0`, `(n/d0) | k` and `binom((1-n)/n, k d0/n) != 0`, i.e. exactly when

      **n >= 2, m >= n, and n | m.**

Verdicts: `n >= 2` and `n | m` — NONVANISHING (nonzero residues, which sum to
zero, control C3 symbolic); otherwise `g = 0` — VANISHING (on `P^1` every
residue-free meromorphic 1-form is exact); otherwise `n > m` — NONVANISHING
(`eta` holomorphic and nonzero on a compact curve of genus `>= 1`); otherwise
deferred to NUM-MONO.

> **An instrument bug found and fixed, recorded because it changed answers.**
> The first version of EXACT-G1 read the residue off the *leading* exponent
> only and concluded "residue nonzero iff `n = m`". That is wrong whenever
> `(n-m)/d0 <= -2`: the `tau^(-1)` coefficient then sits in a *later* term of
> the expansion. The case `n = 2, m = 4` is the smallest witness — NUM-MONO
> reported nonzero residues `0.176777` at each of the two places over
> `x = infinity` there, contradicting the formula, which is how the error was
> caught. The corrected rule `n | m` is what the table above states and what
> NUM-MONO confirms.

> **A second instrument bug, in NUM-MONO, found the same way.** At `n = 3,
> m = 4` EXACT-G1 says VANISHING (all residues zero, genus 0 — Singular's
> `genus` independently returns 0) while NUM-MONO at the original resolution
> reported a period of `1.36` *and* a spurious genus of 1. The cause: the
> adaptive substep validated only the *sheet identification*, never the
> *quadrature error*, so two different resolutions could agree on the same
> wrong value and the two-resolution error estimate looked converged. The fix
> is a genuine adaptive-quadrature control: each panel is computed once on
> `[a,b]` and once as `[a,mid] + [mid,b]`, and the panel is subdivided until
> the difference falls below `1e-9`. After the fix that fibre returns
> `ls_residual = 1.7e-14` and genus 0. **Every NUM-MONO number reported in this
> file is from the fixed instrument.**

### 2.3 NUM-MONO — numerical monodromy periods, any `deg_y`

`mono15.py`. Write `f(x,y) = P(x,y) - c` as a polynomial in `y` of degree `dy`
over `Q[x]`. Off the branch set

    B = { roots of disc_y f } u { roots of lc_y f }        (squarefree parts)

the projection `F_c -> C_x` is a `dy`-sheeted covering, and
`pi_1(C \ B, x_0)` is generated by the loops `gamma_j` = (radial segment from
`x_0` to a point at distance `r_j` from `b_j`) . (full circle about `b_j`) .
(segment back). Lifting `gamma_j` from sheet `k`:

* the sheets are followed by Newton continuation with an **adaptive** substep
  that is validated at every endpoint against the true root set (`np.roots`);
  a failure halves the step;
* `eta = -dx/P_y` is integrated with 8-node Gauss–Legendre on each substep, the
  sheet being carried to every quadrature node;
* this yields a permutation `sigma_j` and values `v_{j,k}`.

A closed cycle of `F_c` is exactly a lift that returns to its starting sheet, so

    **all periods vanish  <=>  there is u : sheets -> C with
     v_{j,k} = u(sigma_j(k)) - u(k)  for all j, k.**

Two things are computed from that:

* a **union-find with weights** over the graph (nodes = sheets, edges
  `k -> sigma_j(k)` of weight `v_{j,k}`): every edge that closes a loop yields
  an explicit period — the witness;
* the **least-squares residual** of the same linear system, which is zero
  exactly when all periods vanish and, unlike "the largest period found", does
  not depend on which spanning tree the union-find happened to build. This is
  the quantity the verdict is taken from.

Loops around ramification points are contractible **in `F_c`** (those points are
honest points of the smooth fibre), so nothing is over-counted; they simply come
out with period `0`, which is itself a running check.

**Places and genus.** Continuation along a large circle `|x| = R` enclosing `B`
gives the monodromy at infinity; its cycles are the places over `x = infinity`,
and (with the sign flip for the clockwise-in-`x` orientation of a local loop
around such a place) the cycle sums are `2 pi i` times the residues there. Over
each root of `lc_y f` the sheets that blow up — their number is the drop in the
`y`-degree at that `x` — form the places with `y = infinity`. Then

    chi(F_c) = dy (1 - |B|) + #{cycles over the b_j that stay finite},
    chi(F_c) = sum over components of (2 - 2 g_i - n_i),

which gives the genus. Monodromy orbits on the sheets give the connected
components (= irreducible components, the fibres being smooth).

**Accuracy.** Every fibre is run twice, at step budget `N` and `2N`; the error
estimate is the difference of the least-squares residuals. The verdict is

* `NONVANISHING` if `ls_residual / scale > 1e-6` and the error estimate is below
  10 % of the residual (`scale` = the largest lifted integral seen),
* `VANISHING` if `ls_residual / scale <= 1e-6`,
* `UNRESOLVED` otherwise.

## 4. The corpus

`gen15.py`. Every member carries: an exact Bezout unimodularity certificate
(`A P_x + B P_y - 1` expanded over `Q`, `0` residual terms), the Shpilrain–Yu
verdict, and an independent fibre witness of non-coordinacy.

### G1 — the v-power family, `P = h0 v + c (x-a)^n v^m`, `v = y + t(x)/2`

Derivation (the way night14 derived F2). With `g = c(x-a)^n` and `v_x = t'/2`,

    P_y = h0 + m g v^(m-1),
    P_x = v_x (h0 + m g v^(m-1)) + g' v^m = v_x P_y + g' v^m,

so on `{P_y = 0}` one has `P_x = g' v^m`. A critical point therefore needs
`v = 0` or `g' = 0`:

* `v = 0` gives `P_y = h0 != 0`;
* `g' = 0` gives `x = a` (since `g' = c n (x-a)^(n-1)`), hence `g = 0`, hence
  `P_y = h0 != 0`.

So the **critical locus is empty for every `m >= 1`, `n >= 1`, `h0 != 0` and
every `t(x)`**. `m = 2` is night14's F2; `m = 3` is species **S1 (v-cubic)`.

### G1' — a derived negative: the mixed `v^2/v^3` member is not unimodular

For `P = h0 v + g1 v^2 + g2 v^3` the same computation gives
`P_x = v_x P_y + v^2 (g1' + g2' v)`, so a critical point needs `v = 0`
(excluded) or `v = -g1'/g2'`. Substituting that `v` into
`P_y = h0 + 2 g1 v + 3 g2 v^2`:

* `g1 = gamma (x-a)^n`, `g2 = delta (x-a)^n` gives `v = -gamma/delta` and
  `P_y = h0 + (gamma^2/delta)(x-a)^n`;
* `g1 = gamma (x-a)^2`, `g2 = delta (x-a)` gives `v = -2 gamma (x-a)/delta` and
  `P_y = h0 + (8 gamma^2/delta)(x-a)^3`;
* `g1` constant nonzero gives a critical point at `x = a`, `v = -h0/(2 g1)`.

In every case `P_y` is `h0` plus a nonzero multiple of a positive power of
`(x-a)`, which has a root over `C`. So inside this shape only the **pure**
`v^m` members are gradient-unimodular. This is a measurement about this shape,
not a statement about mixed families in general.

### G2 — the multiple-root family, `P = alpha x + beta + c B(x) y^m`

with `B = prod (x - a_i)^(e_i)`, every `e_i >= 2`, `alpha != 0`.

    P_y = c m B y^(m-1),      P_x = alpha + c B' y^m.

`{P_y = 0} = {B = 0} u {y = 0}` (the second only for `m >= 2`). On `{y = 0}`,
`P_x = alpha != 0`. On `{x = a_i}`, `B'(a_i) = 0` because `a_i` is a **multiple**
root of `B`, so again `P_x = alpha != 0`. The critical locus is empty.

This family is the source of species **S2 (three or more places at infinity)**:
over each `a_i` the fibre has `gcd(m, e_i)` places with `y -> infinity`, and over
`x = infinity` it has `gcd(m, deg B - 1)`.

### S3 — positive genus

`G1` with `m = 2` and `n >= 3` has `Delta_c = h0^2 + 4 c c_0 (x-a)^n` for
`c != 0`, squarefree with `n` distinct roots, hence genus `floor((n-1)/2) >= 1`.
These are the members that exercise regime B / EXACT-HE case A.

### S4 — fibres with three or more irreducible components

The zero fibre of `P = h0 v + g v^m` is `v (h0 + g v^(m-1))`. Choosing
`h0 = -1`, `g = (x-a)^2`, `m = 3` gives

    P = -v + (x-a)^2 v^3 :  zero fibre = v * ((x-a)v - 1) * ((x-a)v + 1),

three components; `h0 = -1`, `g = (x-a)^4`, `m = 5` gives four.

### S5 — genuinely mixed Newton supports

Composition with a Jacobian-1 automorphism `phi` (a shear in `y` followed by a
shear in `x`) preserves unimodularity, non-coordinacy and the periods, while
turning the support into a genuinely two-dimensional one. Both the base and the
sheared member are screened; agreement is the shear control.

## 5. Screening and the mate solve

`screen15.py`. For each `P`: exact Bezout `U`; Shpilrain–Yu; fibre witness;
then the period screen on the fibres `c = 1, -1, 3/2, 0, 2, -3/5` (EXACT-HE) or
`c = 1, -1` (NUM-MONO). A single fibre with a nonzero period is enough:

* **PERIODS-NONVANISHING** — a mate is obstructed; the witnessing period /
  residue is recorded;
* **PERIODS-VANISHING** — not obstructed by this condition; the survivors.

Survivors go to `mate15.py`: night12's exact linear-algebra kernel
(`matekit`, `exact`, imported read-only) on the carrier of all monomials of
total degree `<= D` with `D = deg P`, `ceil(3 deg P/2)`, `2 deg P`. Verdicts are
`MATE_over_Q` (an exact `Q`, verified by expanding `[P,Q] - 1 = 0`
coefficientwise over `Q`), `EMPTY_over_Q` (with an exactly re-verified lambda
certificate), or `NOT_CERTIFIED` (prime-relative only, never reported as
emptiness). The null directions `Q -> Q + h(P)` lie inside the carrier whenever
`D >= deg P`; they only enlarge the solution space, and the solver reports the
kernel dimension it deflates.

**One addition was needed.** night12's decider emits its lambda certificate only
on the branch `rank_p(A) = n`. With the full triangular carrier the null
directions `Q -> Q + h(P)` are *inside* the carrier, so `rank_p(A) < n` always
and that branch never fires — every survivor came back `NOT_CERTIFIED`. The
certificate does not actually need full rank: `A q = e` is unsolvable over `Q`
iff there is a rational `lambda` with `lambda^T A = 0` on every column and
`lambda^T e = 1`. `mate15.exact_lambda` therefore (i) *finds* a candidate row
combination mod `p` — cheap, and only a heuristic for locating a small support —
and (ii) *solves and verifies* `lambda` exactly over `Q` on that support, via
night12's own `verify_lambda`. Only step (ii) is the certificate; step (i) is
never part of a verdict. Carriers with more than 900 unknowns are recorded as
not certified rather than guessed at.
