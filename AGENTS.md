# Orientation for a new session

Read [`README.md`](README.md) first — it is the map of this repository and it is kept current. It explains:

- what this repository is (a research archive for the plane Jacobian-conjecture campaign) and its one hard rule: no counterexample has been found, and a timeout, a modular result, or a numerical miss is never reported as one;
- which branch to open for the canonical campaign state, and which branches are provenance-only;
- the full list of open (draft) pull requests and what each one covers;
- the evidence rules that govern how a result may be labelled.

Do not start computing before reading `README.md` and, from it, `STATUS.md` and `CATCHES.md` on the canonical campaign branch. `CATCHES.md` is the record of past errors; repeating one of them is the most common way a session wastes its work.

This file and `AGENTS.md` are intentionally thin — they exist only to point an agent at `README.md` on the first turn. Keep the actual content in `README.md` so Claude, Codex, and human readers see the same thing.
