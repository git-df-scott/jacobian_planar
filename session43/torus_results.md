## Verification and interpretation

All weight vectors were verified exactly: for every reported w and every polynomial P_i, <w, e> is a single constant d_i over all exponent vectors e of P_i (checked symbolically, no numeric tolerance). Nullspaces computed exactly over Q via the Gram matrix of the stacked monomial-difference matrix.

### Wave6 TIMEOUT systems (the gold): torus rank 5 (3 nontrivial + 2 free vars)

All six wave6 files (w6_289012_0[_p2], w6_289012_1[_p2], w6_582584_1[_p2]) carry a rank-5 grading torus:

- 2 dimensions are free coordinates: variables c_1 and x appear in NO polynomial at all (spurious free directions -- each alone multiplies the solution count by (p-1) or forces a whole line of solutions; this by itself partially explains solver blowup).
- 3 dimensions are genuine nontrivial gradings mixing essentially ALL the c_i coefficient variables plus w and u, with weights like (for w6_289012_1):
  w2 = (0,0,4,8,1,5,-2,9,2,-5,6,-1,-8,10,3,-4,-11,7,0,11, 0,0,0)
  w3 = (0,-22,-23,-24,-14,-15,-5,-16,-6,4,-7,3,13,-8,2,12,22,1,11,0, 22,0,0)
  w4 = (0,0,3,6,-2,1,-7,4,-4,-12,-1,-9,-17,2,-6,-14,-22,-3,-11,0, 0,22,0)
  (w3 has weight 22 on variable w; w4 has weight 22 on u -- these are gradings under which w resp. u scale.)
  For w6_289012_0 the analogous weights have scale 51 on w/u; for w6_582584_1 scale 26.

This is exactly the "resistance-is-geometry" signature: every TIMEOUT wave6 system sits inside a 3-dimensional (nontrivial) torus of symmetries, so its solution set is fibered into 3-dim torus orbits and Groebner bases must describe whole orbit families.

Torus slice written for each (set c_1=x=1 to kill the free vars, plus 3 grading variables to 1, e.g. c_2=c_3=c_5=1): vars drop 41->36 or 23->18, polynomial count unchanged. Files *_torus_sliced.ms next to this report. Caveat: setting v=1 selects the chart v != 0; the v=0 stratum must be handled separately (recursively -- it inherits the remaining grading) for a complete decomposition.

### Wave5 ms2 systems: rank 1 in every *_Z_* variant, rank 0 in every *_N_* variant

A perfect split: all "Z-seed" systems have a rank-1 grading, weight -1 on mu0 and +1 on t (i.e. the product mu0*t and the ratio t/mu0 are the invariants; the torus acts by mu0 -> s^-1 mu0, t -> s t). The "N-seed" counterparts have rank 0 (no grading -- consistent with N systems being the normalized versions). d12seedZ_unsat / ctl_d3seedZ_unsat carry weight +1 on mu0 alone (t absent there): mu0 appears homogeneously and can be scaled away.
