## Task 1 — The H1c refutation

**The claim under test** (wave 1 §2.1, tagged `[PROVED-exact]`): for the endgame equation

```
T_{D,k}(R) := (v+1)^k · ( 3 v (v+1) R'(v) − D R(v) )  =  −c ,      c ≠ 0
```

no rational `R` exists when `k ≥ 1`, "because the left side vanishes at `v = −1`
and the right side does not."

**Why it is invalid.** Evaluation at `v = −1` is legal only when `R` is regular there.
The statement quantifies over *rational* `R`, which may have a pole at `v = −1`. A pole
of order `k+1` makes the left side finite and nonzero at `v = −1` and the argument
evaporates.

**The counterexample, certified exactly with `c` symbolic:**

```
D = 6 ,  k = 1 ,  R = c / (6 (v+1)^2)      ⟹   T_{6,1}(R) = −c   exactly
```

**The full picture, not just one counterexample.** Poles of any rational solution are
confined to `v = −1` (Lemma POLE-LOC, proved and machine-checked), so `R` is a Laurent
polynomial in `U = v+1` and the equation becomes a two-term recurrence. Running it out:

> **THEOREM W2-1.** For `c ≠ 0`, integer `D ≥ 1`, `k ≥ 0`, the equation `T_{D,k}(R) = −c`
> has a rational solution **iff** `D/3 ∉ {0, 1, …, k}` — that is, iff `D ∉ {3, 6, …, 3k}`.
>
> When a solution exists, one is `R = N(v)/(v+1)^k` with `deg N ≤ k`, seeded at
> `c₀ = (−1)^k · c · k! / (3 ∏_{i=0}^{k} (D/3 − i))` and generated by
> `c_{j−1} = [ (j + D/3) c_j − (c/3)·[j = −k] ] / (j − 1)`.

Machine-verified on the full grid `D = 1..25`, `k = 0..5` (150 cells, zero mismatches),
by two independent code paths (a sympy expansion path and the recurrence path), each of
which is shown to reject a deliberately wrong closed form.

**What survives.** The theorem *is* true under the extra hypothesis "`R` polynomial"
(CHECK P: no polynomial solution of degree ≤ 20 at `D ∈ {6,13,23}`, `k ∈ {1,2,4}`, while
the `k = 0` control is solvable). The wave-1 statement omitted that hypothesis.

**The rigged certifier.** `w1_h1c_endgame_closed_form.py:89` reads
`check("k >= 1 forces c = 0...", True, ...)` — the condition is a literal `True`. It
certified precisely the statement refuted above and could never have failed.
