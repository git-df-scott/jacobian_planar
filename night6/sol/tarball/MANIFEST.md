# Manifest

One-command verification after extraction:

    python3 run_all.py

Dependencies: Python 3, `sympy`, and `jsonschema`.

| file | claim | checker |
|---|---|---|
| `triage.schema.json`, `TRIAGE_SCHEMA.md` | frozen `jc2.face-triage.v1` contract | `triage_check.py` |
| `triage.json` | 34 published rows plus six ranked extensions; polygons, faces, rules, budgets, caveats, verdicts, dossiers, level-one cascades | `triage_check.py` |
| `cases/*.md` | one derivation note per row/extension | mechanically generated by `triage_generate.py` |
| `TRIAGE_REPORT.md` | compact all-case inventory and tally | generated from `triage.json` |
| `triage_generate.py` | lattice, face, rule, kill, budget, and cascade generator | `triage_check.py` independently recomputes rules |
| `face_families.json` | explicit normalized recurrence coordinates for all nine edge-ODE types | `face_families.py`, `face_hurwitz_general.py` |
| `face_hurwitz_general.py` | characteristic-zero existence and counts for all survivor ODE types | Frobenius/Murnaghan–Nakayama engine in `case1_hurwitz.py` |
| `COVERAGE_84_126.md` | exact statement of the missing coverage lemma and the F9 counter-control | `coverage_negative_control.py` |
| `SURVIVORS.md` | published-exact survivors, symmetries, dimensions, and cascade summaries | `triage.json`, `face_families.json` |
| `trackD_chain_map.py` | campaign's conditional chain-to-carrier generator | six built-in positive controls plus the F9 negative control |
| `case1_hurwitz.py` | character-theoretic cover counter | its `validate` mode brute-forces small symmetric groups |

Interpretation guard: `conditional_pattern_verdict` is never a promoted case
verdict unless `coverage.level` is `published_exact`. In particular,
`GGHV34-14` has fourteen checked chart kills but remains `UNCLEAR` because the
coverage map lacks—and now demonstrably needs—a case-specific proof.
