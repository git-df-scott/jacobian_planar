# JC2 complete-frontier essential-face triage

Start with `TRIAGE_REPORT.md`, then `COVERAGE_84_126.md` and `SURVIVORS.md`.
The full machine object is `triage.json`; its frozen contract is
`triage.schema.json`.

The audit deliberately separates two statements:

1. the coefficient rules and vertex kills of an emitted reduced chart;
2. proof that a published GGHV chain must reduce to one of those charts.

The first is checked for 392 target-weight faces. The second is available from
the cited paper for only four rows in this package. The F9 Proposition 4.4
control shows that the former campaign extrapolator is not a universal theorem,
so every other main verdict remains `UNCLEAR` even when its conditional charts
are all killed.
